Дробная часть.
Дана сигнатура функции: double fraction (double x);
Необходимо реализовать функцию таким образом, чтобы она возвращала только дробную часть числа х. Подсказка: вещественное число может быть преобразовано к целому путем отбрасывания дробной части.

Вернуть значение frac_part.
Пример: x = 5,25 → part = 5, frac_part = 5,25 − 5 = 0,25.
В main число x вводится с клавиатуры; если введено не число, выводится сообщение об ошибке, поток ввода очищается (cin.clear(), cin.ignore()) и запрос повторяется.
